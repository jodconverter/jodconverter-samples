Sample JODConverter applications
================================

The projects in this directory demonstrate typical use cases using the JODConverter project. They include:

- [`basic-webapp`](./basic-webapp): Demonstrates how to use the [jodconverter-local-lo](https://github.com/jodconverter/jodconverter/tree/master/jodconverter-local-lo) module to build a basic web application.
- [`spring-boot-rest`](./spring-boot-rest): Demonstrates how to use the [jodconverter-spring-boot-starter](https://github.com/jodconverter/jodconverter/tree/master/jodconverter-spring-boot-starter) module to build a REST API supporting document conversions.
- [`spring-boot-webapp`](./spring-boot-webapp): Demonstrates how to use the [jodconverter-spring-boot-starter](https://github.com/jodconverter/jodconverter/tree/master/jodconverter-spring-boot-starter) module to build a web application with bootstrap.
- [`spring-boot-remote`](./spring-boot-remote): Demonstrates how to use the [jodconverter-remote](https://github.com/jodconverter/jodconverter/tree/master/jodconverter-remote) module to convert with a Collabora Online server, without an office beside the application.
- [`spring-boot-attached`](./spring-boot-attached): Demonstrates how to use the attached office manager of the [jodconverter-local](https://github.com/jodconverter/jodconverter/tree/master/jodconverter-local) module to convert with a LibreOffice that runs in a container, which the application does not start.
